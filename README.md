# Student-Exam-Success-Prediction-using-Probability-and-Bernoulli-Distribution
This project applies probability theory and the Bernoulli distribution to predict student exam success outcomes based on key academic and behavioral features. By modeling exam results as a binary random variable (pass/fail), the system estimates success probabilities using statistical learning techniques.
Student Exam Success Prediction using Probability and Bernoulli Distribution
📌 Overview

This project focuses on predicting whether a student will pass or fail an exam using probability theory and the Bernoulli distribution. Each student's outcome is treated as a binary event (success = 1, failure = 0), allowing us to model academic performance using statistical methods.

The goal is to understand how different factors influence exam success and estimate the probability of a student passing based on historical data.

🧠 Concept Used
Bernoulli Distribution
Probability Theory
Binary Classification (Pass/Fail)
Statistical Inference

A Bernoulli random variable is defined as:

X=1 → Student passes
X=0 → Student fails

Probability of success:

P(X=1)=p,P(X=0)=1−p
📊 Features Considered

The model may use factors such as:

Attendance rate
Study hours
Assignment completion
Previous exam scores
Class participation
⚙️ Methodology
Data collection and preprocessing
Feature selection
Probability estimation for success rate
Application of Bernoulli distribution model
Prediction of pass/fail outcome
Evaluation of model performance
📈 Output

The system predicts:

Probability of student passing the exam
Final classification: Pass / Fail
